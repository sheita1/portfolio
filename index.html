Proyecto: Junta de Vecinos

         

Plataforma institucional desarrollada para digitalizar los procesos administrativos de una comunidad local. Permite registrar vecinos, gestionar reuniones, adjuntar actas en PDF y mantener un historial documental accesible.

         
               
  • Stack Principal: PERN (PostgreSQL, Express.js, React, Node.js)
    •            
  • Funcionalidades Clave: Registro de vecinos, gestión de reuniones, actas PDF, panel administrativo robusto.
    •            
  • Despliegue: Contenedores Ubuntu en infraestructura universitaria
    •

Proyecto: Taller de Desarrollo (Software para Turistas)

         

Software desarrollado para mejorar la experiencia turística en sitios patrimoniales mediante la tecnología QR. Al escanear el código, el turista es dirigido automáticamente a la información detallada del patrimonio.

         
               
  • Stack Principal: PERN (PostgreSQL, Express.js, React, Node.js)
    •            
  • Funcionalidades Clave: Lector/Escáner QR, Panel de administración para gestión de patrimonios (CRUD), y módulo de subida de imágenes.
    •            
  • Arquitectura: Full-Stack, con React como *frontend* y Node/Express para manejar la API y la persistencia de datos en PostgreSQL.
